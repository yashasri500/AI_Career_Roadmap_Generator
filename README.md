# 🚀 AI Career Roadmap Generator

An AI-powered web application that generates personalized career roadmaps based on a user's qualification, skills, and career goals.

## ✨ Features

- 🔐 User Login & Registration
- 🎯 Personalized AI Career Roadmap
- 📊 Career Readiness Analysis
- 🗺️ Step-by-Step Career Roadmap
- 🤖 AI Career Mentor Chat
- ✅ Career Preparation Check
- 📄 Download Career Roadmap PDF
- 📚 Download Full Career Report PDF
- 📜 Roadmap History

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- SQLite
- ReportLab
